# CSSEC Claude Design Reference

This directory contains the exported Claude Design prototype.

It is reference material only.

Do not treat this directory as production source code.
Do not install its dependencies into the main application.
Do not copy its project configuration over the production project.

Use it to reproduce:

- visual hierarchy
- layouts
- responsive behavior
- typography
- colors
- components
- interactions
- spacing
- page structure

The production implementation lives under `src/` and must follow the
existing Next.js, Sanity, Clerk, TypeScript, and Tailwind architecture.
